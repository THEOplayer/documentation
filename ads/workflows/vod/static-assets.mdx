# Static assets on VOD

import Layouts from '../_shared/_static-assets-layouts.mdx';
import Formats from '../_shared/_static-assets-formats.mdx';
import Troubleshooting from '../_shared/_static-assets-troubleshooting.mdx';

With static assets, each break points directly at its ad creatives: video or image files that you host on your own CDN. No ad server is involved — the SDK fetches the creative from the URL on the break and plays it when the viewer reaches the break. Use this workflow on movies, episodes, replays, and clips for direct-sold campaigns, sponsorships, promos, and branded overlays where you already know which creative to show.

|                | Static assets on VOD                                                       |
| -------------- | -------------------------------------------------------------------------- |
| Delivery mode  | Server-guided (SGAI)                                                       |
| Ad decisioning | None: the break names the creative                                         |
| Break creation | Scheduled at positions in the asset, or detected from the ad markers in it |
| Your app needs | The OptiView Ads SDK for your platform; nothing else                       |

## Before you start

- A [VOD channel](./index.mdx#set-up-a-vod-channel). The examples use the `mediatime` timebase.
- The OptiView Ads SDK in your app: [Web](../../player-integration/optiview-ads-sdk/web.mdx), [Android](../../player-integration/optiview-ads-sdk/android.mdx), [iOS](../../player-integration/optiview-ads-sdk/ios.mdx), or [React Native](../../player-integration/optiview-ads-sdk/react-native.mdx). Static assets need no ad server, no Google Ad Manager account, and no extra configuration in the app.
- Your creatives on a CDN that the viewers' devices can reach.

## Schedule a break

A static asset sets `type` to `static` and `uri` to the URL of the creative. On a `mediatime` channel, `start` is the position in the asset, in seconds. This mid-roll plays 10 minutes in, and viewers cannot skip it by seeking:

```bash
curl -X POST 'https://us.ads.optiview.dolby.com/api/v1/channels/<channel-id>/breaks' \
  -u "$ADS_API_KEY:$ADS_API_SECRET" \
  -H 'Content-Type: application/json' \
  -H 'X-Org-ID: <org-id>' \
  -d '{
    "start": 600,
    "duration": 30,
    "controls": { "snapback": true },
    "variant": {
      "format": "single",
      "assets": [
        {
          "type": "static",
          "mediaType": "video",
          "mimeType": "application/x-mpegurl",
          "uri": "https://cdn.example.com/ads/spot.m3u8",
          "interaction": { "clickThrough": "https://www.example.com/offer" }
        }
      ]
    }
  }'
```

The `uri` can also be a list of URLs targeted per device type. See [Static assets](../../concepts/breaks.mdx#static-assets) and [Asset URI targeting](../../concepts/breaks.mdx#asset-uri-targeting) for the full asset model.

### Pre-roll, post-roll, and pause ads

Set `start` to a player event instead of a position:

| Break     | `start`                                 |
| --------- | --------------------------------------- |
| Pre-roll  | `{ "type": "event", "event": "start" }` |
| Post-roll | `{ "type": "event", "event": "end" }`   |
| Pause ad  | `{ "type": "event", "event": "pause" }` |

A pause ad is typically an image in the `overlay` layout. See [Event based triggers](../../concepts/breaks.mdx#event-based-triggers).

### Detect the breaks

Instead of scheduling every break, add the asset as an [origin](../../concepts/origins.mdx) and configure a [marker rule](../../concepts/marker-detection.mdx) whose [template](../../concepts/templates.mdx) holds the static assets. Every matching ad marker in the asset, such as an SCTE-35 signal, becomes a break at its position.

## How the break plays

- The SDK fetches the channel's [Break Manifest](../../concepts/break-manifest.mdx) once when the session starts. It lists every break, and the SDK loads each creative shortly before its break.
- With `snapback`, a viewer who seeks past a break is taken back to the break first; afterwards, playback continues where the viewer was seeking to. Without it, viewers can skip the break by seeking. See [Seeking and snapback](./index.mdx#seeking-and-snapback).
- A break plays at most once per session.

## Tracking and reporting

The SDK reports an OptiView Ads [impression](../../how-to-guides/ad-impressions.md) for every break it presents, and emits ad events — such as the start and end of each break and ad — that your app can listen to. See the API reference of your platform for the full list of events.

Static assets carry no third-party tracking URLs. If an advertiser needs to count impressions in their own ad server, deliver the creative through a [VAST tag](./vast.mdx) instead: the VAST response carries the advertiser's tracking URLs, which are fired while the ad plays.
