The SDK reads the Google settings — your network code and the channel's Google asset key — from the channel's Break Manifest, and starts the Google stream session automatically when the session starts. You do not configure them in the app, so your app and the backend always agree on which Google stream the ads belong to.

| Platform     | Requirement                                                                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web          | Load Google's IMA DAI SDK on the page, before your application script (see below).                                                                                                                                  |
| Android      | Nothing extra: the SDK runtime includes the Google IMA SDK.                                                                                                                                                         |
| iOS and tvOS | Nothing extra: the runtime pod includes the Google IMA SDK. With Swift Package Manager, add the Google IMA packages as described in [iOS](../../player-integration/optiview-ads-sdk/ios.mdx#swift-package-manager). |
| React Native | Nothing extra: the native SDKs include the Google IMA SDK.                                                                                                                                                          |

On Web, add the IMA DAI loader to your page:

```html
<script src="https://imasdk.googleapis.com/js/sdkloader/ima3_dai.js"></script>
```

If your channel also has VAST breaks, load `ima3.js` as well; the two scripts work side by side.
