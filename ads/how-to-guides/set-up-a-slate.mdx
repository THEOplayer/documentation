# Set up a slate

A slate is an image or a video that players show during the part of a break that no ad covers: the whole break when no ad can play, or the rest of the break when the ads end early. You can save a slate once for several channels or set an asset on just one channel. See [Slate](../concepts/breaks.mdx#slate) for exactly when the slate plays.

## Before you start

- A [channel](../concepts/channels.mdx). The slate applies to every break of the channel, live or VOD.
- The OptiView Ads SDK **1.6.0 or later** in your app, on [Web](../player-integration/optiview-ads-sdk/web.mdx), [Android](../player-integration/optiview-ads-sdk/android.mdx), [iOS](../player-integration/optiview-ads-sdk/ios.mdx), or [React Native](../player-integration/optiview-ads-sdk/react-native.mdx). See [Platform support](../concepts/breaks.mdx#platform-support) for the platforms that do not show a slate yet.

## Prepare the slate media

A slate is one [static asset](../concepts/breaks.mdx#static-assets): an image or a video that you host yourself.

- **Video.** Use HLS (recommended) or MP4. An HLS slate must be an on-demand playlist that ends with `EXT-X-ENDLIST`; a live stream cannot be a slate.
- **Image.** Use a still or animated image, such as a PNG, JPEG, GIF, or WebP, in the aspect ratio of your player, for example 1920×1080 for 16:9. The image stays on screen for as long as the slate plays.
- **Match your content.** OptiView Ads does not transcode the slate: players play it as you provide it. Encode a video slate like your content — the same renditions (resolutions and bitrates), codec, and frame rate — so it looks and plays like the rest of your stream on every device.
- **Keep it short.** A video slate plays from its start and repeats for as long as the break needs, so a loop of a few seconds to half a minute is enough. The slate is cut at the end of the break.
- **Host it publicly.** The URL must be a public `http(s)` URL that the viewers' devices can reach. On Web, your CDN must allow cross-origin requests (CORS) from your app's origin, as for your other creatives.

OptiView Ads does not check whether the slate plays. The Dashboard's **Preview** shows it in your browser; also test it on your devices before you turn it on for viewers.

### Different media per device

The player uses the slate asset even when it cannot play it, and does not fall back to other media. To give each device media it can play, set `uri` to a list of URLs with [targeting](../concepts/breaks.mdx#asset-uri-targeting), like the URI of any static asset:

```json
"uri": [
  { "value": "https://cdn.example.com/slates/brand/tv/master.m3u8", "targeting": { "deviceType": "tv" } },
  { "value": "https://cdn.example.com/slates/brand/master.m3u8" }
]
```

The first entry that matches the device is used; the entry without `targeting` covers every other device. All entries share the asset's `mediaType`, so a slate is either an image or a video on every device. On devices where the ad and the content share one video element, such as iPhone Safari, only a video slate is shown.

## Create a reusable slate

### In the Dashboard

1. In the OptiView Unified Dashboard, open **Ads → Slates** and click **New**.
2. Enter a **Name** and add an image or video asset. Set **Minimum remaining duration (seconds)** if you want a different minimum than 5 seconds.
3. To make this the organization default, turn on **Default slate**. Click **Preview** to check the media, then **Save**.

To set an existing slate as the default, choose **Make default** for that slate. Only one slate can be the default. Channels set to **Organization default** follow the change; channels that selected a specific slate keep using that slate.

### With the Ads API

Create a slate under `/api/v1/organizations/slates`. The `X-Org-ID` header identifies the organization. This example creates a slate and makes it the default:

```bash
curl -X POST 'https://us.ads.optiview.dolby.com/api/v1/organizations/slates' \
  -u "$ADS_API_KEY:$ADS_API_SECRET" \
  -H 'Content-Type: application/json' \
  -H 'X-Org-ID: <org-id>' \
  -d '{
    "name": "Brand slate",
    "minDuration": 5,
    "isDefault": true,
    "assets": [
      {
        "type": "static",
        "mediaType": "image",
        "uri": "https://cdn.example.com/slates/brand.png"
      }
    ]
  }'
```

Copy the response's `id` to select this slate on a channel. Use `GET /api/v1/organizations/slates` to list the organization's slates. To read, update, or delete a slate, use `GET`, `PATCH`, or `DELETE` on `/api/v1/organizations/slates/{slateId}` with the same header. A `PATCH` changes only the fields you send. To make an existing slate the default, send `{"isDefault": true}`. A `PATCH` that carries `assets` must include the asset `id`: its current `id` to update that asset, or a new `id` to replace it. Without an `id`, the request returns `400`.

## Set the slate on a channel

### In the Dashboard

1. In the OptiView Unified Dashboard, open **Ads → Channels** and select the channel.
2. On the **Breaks** tab, click **Add** on the **Slate** card, or **Edit** if the channel already has a slate setting.
3. Choose a source:
   - **Organization default** follows whichever slate is the organization's default.
   - **Organization slate** lets you pick a saved slate by name. If that slate is deleted, the channel shows no slate; it does not fall back to the default.
   - **Own asset** lets you give the channel its own slate. Enter a **Name** and provide the asset's **Media Type** and **URI**. You can also set **Device-specific URIs**, **MIME type**, **Asset Parameters**, and a **Click-through URL**.
4. Set **Minimum remaining duration (seconds)** to override the minimum. Leave it empty to use the minimum of the organization slate the channel uses, or 5 seconds.
5. For **Own asset**, click **Preview** to check the media. Click **Save**. To preview a saved organization slate after assigning it, use **View** on the **Slate** card.

Creating an organization default does not turn on slates for channels that have none configured. If the channel has no slate and the organization has a default, you can turn on the switch on the **Slate** card to start using the default. Turn the switch off to stop showing the slate without losing your settings. To clear the channel's slate settings, click **Delete** and confirm the removal. This does not delete a saved organization slate.

### With the Ads API

Set `slate` when you create or update a channel. To use a saved slate, send its organization slate ID as `slateId`:

```bash
curl -X PATCH 'https://us.ads.optiview.dolby.com/api/v1/channels/<channel-id>' \
  -u "$ADS_API_KEY:$ADS_API_SECRET" \
  -H 'Content-Type: application/json' \
  -H 'X-Org-ID: <org-id>' \
  -d '{ "slate": { "enabled": true, "slateId": "<slate-id>" } }'
```

To follow the organization default, send `{"slate": {"enabled": true}}`. The channel shows no slate while there is no default. Do not send `slateId` and `assets` together. A `slateId` that does not exist returns `404`, unless it is the one already stored on the channel: resending the stored `slate` object keeps working after that slate is deleted.

To set the channel's own slate, send `assets` instead of `slateId`:

```bash
curl -X PATCH 'https://us.ads.optiview.dolby.com/api/v1/channels/<channel-id>' \
  -u "$ADS_API_KEY:$ADS_API_SECRET" \
  -H 'Content-Type: application/json' \
  -H 'X-Org-ID: <org-id>' \
  -d '{
    "slate": {
      "name": "Brand slate",
      "minDuration": 5,
      "assets": [
        {
          "type": "static",
          "mediaType": "video",
          "mimeType": "application/vnd.apple.mpegurl",
          "uri": "https://cdn.example.com/slates/brand/master.m3u8",
          "interaction": { "clickThrough": "https://www.example.com/brand" }
        }
      ]
    }
  }'
```

- `enabled` defaults to `true` when you send a slate object.
- `name` is optional and is not part of the Break Manifest.
- `minDuration` is the break time in seconds (≥ 0) that must remain for the player to start the slate. A channel using a saved slate or the default takes that slate's `minDuration` when it sets none; otherwise the player uses 5 seconds. Set it to `0` to allow the slate to start for any remaining time.
- `assets`, when supplied, must contain exactly one [static image or video asset](../concepts/breaks.mdx#static-assets), without `duration`. It accepts a media URL or [targeted URLs](#different-media-per-device), plus optional `mimeType`, `assetParameters`, and `interaction.clickThrough`.
- The asset's `id` identifies it in reporting. If there is no stored asset, the API generates an ID when you omit it. When updating an existing asset, send its current `id` to keep its identity or a new `id` to replace it. Omitting the ID in that case returns `400`.

A channel update replaces the whole `slate` object. To turn it off without clearing the settings, resend the stored object with `enabled: false`. For example, for the channel using the saved slate above, send `{"slate": {"enabled": false, "slateId": "<slate-id>"}}`. To clear the channel's slate settings, send `null`:

```bash
curl -X PATCH 'https://us.ads.optiview.dolby.com/api/v1/channels/<channel-id>' \
  -u "$ADS_API_KEY:$ADS_API_SECRET" \
  -H 'Content-Type: application/json' \
  -H 'X-Org-ID: <org-id>' \
  -d '{ "slate": null }'
```

## Check the Break Manifest

When the channel's slate is on and its source is available, the [Break Manifest](../concepts/break-manifest.mdx) carries the resolved slate at the top level, next to the breaks:

```json
{
  "slate": {
    "minDuration": 5,
    "assets": [
      {
        "id": "4f2b8c6e-1d3a-4e59-9b7f-0a6c2e8d1f35",
        "type": "static",
        "mediaType": "video",
        "mimeType": "application/vnd.apple.mpegurl",
        "uri": "https://cdn.example.com/slates/brand/master.m3u8",
        "interaction": { "clickThrough": "https://www.example.com/brand" }
      }
    ]
  },
  "breaks": []
}
```

A change to the slate reaches players with the next manifest poll on a live channel, and with the next playback session on a VOD channel. Editing or deleting a saved organization slate changes every channel that uses it in the same way. It applies the next time a slate starts. A slate that is already playing continues until its break ends.

## What viewers see

Take a 60-second break with a single 30-second ad, on the channel above:

```json
{
  "start": "2026-07-16T12:15:00.000Z",
  "duration": 60,
  "variant": {
    "format": "single",
    "assets": [
      {
        "type": "static",
        "mediaType": "video",
        "mimeType": "video/mp4",
        "uri": "https://cdn.example.com/ads/spot-30s.mp4",
        "duration": 30
      }
    ]
  }
}
```

| Break                              | 0–30 seconds | 30–60 seconds | At 60 seconds        |
| ---------------------------------- | ------------ | ------------- | -------------------- |
| Partly unfilled: the ad plays      | The ad       | The slate     | Your content returns |
| Fully unfilled: the ad cannot play | The slate    | The slate     | Your content returns |

Without a slate, the partly unfilled break returns to your content after 30 seconds, and the fully unfilled break returns to it right away.

- A video slate always starts from its beginning and repeats when it is shorter than the time it covers.
- In a Double Box or L-shape ad break, the slate plays in the ad box, and the companion stays on screen. See [How the slate plays](../concepts/breaks.mdx#how-the-slate-plays).
- When the slate has a click-through URL, a click on the slate uses the slate's URL, never the URL of the ad before it.
- When the slate cannot load or play, the SDK emits an `aderror` event that carries the slate asset, and your content returns as without a slate. Listen for it while you test.
