OptiViewAds

OptiView Ads SDK for Roku, version 1.3.0

SceneGraph component that inserts OptiView Ads breaks into clear live HLS on Roku through one application-owned Video node: client-side stitching of Google Ad Manager pods (SGAI), or the channel's Google DAI live stream when the break manifest selects server-side ad insertion for TV devices (SSAI).

Functions

Call with CallFunc. Asynchronous calls return an operation ID and report through operationresult events; getters return snapshots. Register listeners with addEventListener(eventType, listenerOwner, listenerName): the owner is the application's node and the listener one of its interface functions, invoked with the event as its argument.

addEventListener

addEventListener(eventType as String, listenerOwner as Object, listenerName as String)

Subscribes listenerOwner.listenerName to an event type (see Events). listenerOwner is the application's node (usually m.top) and listenerName one of its interface <function>s, invoked with the event as its single argument: m.ads.callFunc("addEventListener", m.ads.events.adbreakbegin, m.top, "onAdBreakBegin").

removeEventListener

removeEventListener(eventType as String, listenerOwner as Object, listenerName as String)

Removes a listener added with addEventListener (same event type, owner and function name). Unknown listeners are ignored.

startSession

startSession(config as Object) as Integer

Starts a session for one channel and returns an operation ID. Results arrive as operationresult events; on ready, load its playbackUrl into a ContentNode (streamFormat: "hls") on the bound Video. ready waits until the first break manifest has decided the delivery mode; if that manifest fails, the session continues content-first in SGAI. A new startSession supersedes the previous session.

Operation statuses: ready, error, cancelled

endSession

endSession() as Integer

Ends ad insertion. While playback is still attached it reports draining (playback-detach-required) and keeps the published stream available; stop and detach the Video, then the session reports ended.

Operation statuses: ended, draining

destroy

destroy() as Integer

Releases the component's workers. Refuses with playback-detach-required while the Video still uses the SDK's URL; stop and detach playback first. Listeners stay registered so later calls still report error (destroyed).

Operation statuses: destroyed, error

updateAssetParameters

updateAssetParameters(parameters as Object) as Integer

Replaces the runtime ad tag parameters used for future breaks (merged with the start config and manifest parameters). A break already committed is not changed. Requires an active session.

Operation statuses: updated, error

updateAssetParameterMacros

updateAssetParameterMacros(update as Object) as Integer

Sets or removes macro values: { set: { NAME: value }, remove: ["NAME"] }. Requires an active session.

Operation statuses: updated, error

updateRafMetadata

updateRafMetadata(metadata as Object) as Integer

SSAI: updates the Roku Advertising Framework content metadata { contentId, contentGenre, kidsContent, contentLength }.

Operation statuses: updated, error

getAdBreakStatus

getAdBreakStatus() as Object

Snapshot of the break state: phase, state, generation, ticking, the selected break and its countdown, all known breaks (breakId, occurrence, state, reason, reasonDetail) and deliveryMode. When playback must be restarted it adds recoveryRequired, reloadRequired and reloadReason.

isSessionActive

isSessionActive() as Boolean

Whether ad insertion is starting or active. It does not report whether the Video is playing.

getSessionInfo

getSessionInfo() as Object

Snapshot of the session: generation, active, destroyed and, during a session, state, playbackEpoch, recoveryRequired, reloadRequired, channelId, deliveryMode, deliveryModeSource and publishedSourceEnd (UTC, ISO 8601) when available.

getCapabilities

getCapabilities() as Object

Describes what the installed version implements (see Capabilities). Check it instead of assuming a feature.

resolveGateway

resolveGateway(result as Object) as Boolean

Answers a gatewayrequest event: { requestId, generation, status, value } with status "ok" or "error". Returns false for an unknown or stale request. Without an answer within two seconds the SDK uses the original request, response or registered macro values and reports a diagnostic.

Events

Event types for addEventListener. Every event carries type and generation; ad, break, status and diagnostic events also carry a sequence, operationresult an operationId and gatewayrequest a requestId. Tracking events come only from genuine IMA callbacks.

A ready result of startSession carries playbackUrl, deliveryMode and, in SSAI, ssaiStream. See Operation results.
diagnosticDiagnostics with code, an optional reason and code-specific context (see Diagnostics).
gatewayrequestInterception and macro requests (kind: manifest-request, manifest-response or asset-parameter-macros) with requestId, generation, value and context. Answer each with resolveGateway within two seconds.
adbreakbeginA break started playing at its actual splice point.
adbeginAn ad in the pod started (from a genuine IMA callback).
adfirstquartileFirst quartile of the current ad.
admidpointMidpoint of the current ad.
adthirdquartileThird quartile of the current ad.
adendThe current ad completed.
adbreakendThe break completed.
aderrorAn ad or break failed. A failure after publication also sets recoveryRequired; start a new session.
adbreakskippedA break was refused before anything was shown and content kept playing. reason: late, not-ready, preparation-failed, unsupported, overlap, start-delay, removed, insufficient-remaining or resource-limit; reasonDetail names the specific cause, with podEvidence or preparationEvidence where available.
adbreakstatusBreak state and countdown updates (same shape as getAdBreakStatus).
adchannelchangeThe break manifest moved to another ads channel; carries previousChannelId, channelId, previousDeliveryMode and deliveryMode.
playbackreloadrequiredPlayback must be restarted in a new session (for example delivery-mode-changed, ssai-stream-changed, or a viewer seek that fenced tracking).
adinteractiveexitSSAI: the viewer left a Roku Advertising Framework interactive ad; stop playback and restore focus.
