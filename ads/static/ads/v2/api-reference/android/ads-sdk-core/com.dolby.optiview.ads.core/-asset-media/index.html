AssetMedia

data class AssetMedia(val kind: AssetMediaKind?, val format: AssetMediaFormat?, val mimeType: String?, val source: AssetMediaSource?, val issue: AssetMediaIssue?)

How the SDK handles an asset's media (mirrors the TS AssetMedia). A declared mimeType the SDK recognises decides kind and format; otherwise mediaType decides kind, and the URL or the file content decides the format.
