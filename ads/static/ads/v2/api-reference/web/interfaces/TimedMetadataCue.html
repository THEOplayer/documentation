    Interface TimedMetadataCue

    One in-stream timed-metadata marker (payload of timedmetadata). Minimal, player-agnostic:

    • id3: HLS ID3 — parsed text frames and/or undecoded raw bytes.
    • daterange: HLS EXT-X-DATERANGE — id / schemeIdUri / messageData.
    • emsg: DASH/CMAF event message — schemeIdUri / messageData.
    interface TimedMetadataCue {
        description?: string;
        endTime?: number;
        frames?: Record<string, string>;
        id?: string;
        messageData?: string;
        mimeType?: string;
        phase?: "parsed" | "presented";
        raw?: Uint8Array<ArrayBufferLike>;
        schemeIdUri?: string;
        startTime: number;
        type: "id3" | "daterange" | "emsg";
    }

    Marker identifier (EXT-X-DATERANGE ID / emsg id).

    OptionalmessageData

    messageData?: string

    emsg message data, daterange client attribute, or the decoded (UTF-8) data of an ID3 GEOB frame.

    OptionalmimeType

    mimeType?: string

    ID3 GEOB MIME type (e.g. application/json), when surfaced.

    Optionalphase

    phase?: "parsed" | "presented"

    WHEN this delivery happened relative to startTime. parsed: the segment was demuxed — arrives early by the buffer-ahead (20-30s measured on hls.js), enabling scheduling and preload. presented: the playhead reached the cue (frame-accurate; ExoPlayer onMetadata and AVPlayer metadata output deliver here). Omitted means unknown: an adapter that cannot tell must leave it undefined, since labelling parsed as presented would fire breaks 20-30s early.

    Optionalraw

    raw?: Uint8Array<ArrayBufferLike>

    Undecoded marker bytes (ID3/emsg), when available.

    OptionalschemeIdUri

    schemeIdUri?: string

    Scheme URI (EXT-X-DATERANGE scheme / emsg schemeIdUri).

    startTime

    startTime: number

    Presentation time of the marker, in seconds.

    type

    type: "id3" | "daterange" | "emsg"

    Marker source type.
