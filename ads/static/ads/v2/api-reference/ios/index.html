OptiView Ads SDK for iOS/tvOS

API reference for version 1.0.0-beta.6-custom.1364, one DocC module per Swift package. Start with OptiViewAdsSDK for the integration API and OptiViewAdsRuntime for the UIKit renderer.

  • OptiViewAdsCore — Break-manifest model, PlayerAdapter contract and diagnostic taxonomy.
  • OptiViewAdsSDK — OptiViewAds entry point, configuration, sessions and events.
  • OptiViewAdsRuntime — AVFoundation ad rendering, Google IMA and overlay playback for UIKit apps.
  • OptiViewAdsReactBridge — Native side of the React Native package.
  • OptiViewAdsAdapterTHEOplayer — PlayerAdapter for the THEOplayer iOS/tvOS SDK.
  • OptiViewAdsAdapterTestKit — Conformance tests for custom PlayerAdapter implementations.
