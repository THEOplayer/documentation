# DVR

Use the seekable window to rewind a live stream or jump back to the live edge.

import CodeBlock from '@theme/CodeBlock';
import DvrDemo from './_components/DvrDemo';
import demoSource from '!!raw-loader!../static/theoplayer/v11/examples/dvr/demo.html';

<DvrDemo />

A live stream can have `duration === Infinity`. The `seekable` ranges show the part of the live stream that is available for seeking.
Open Video UI uses a live button to return to the end of the window.

```js
const lastRange = player.seekable.length - 1;
const liveEdge = player.seekable.end(lastRange);
player.currentTime = liveEdge - 30;
```
