By default the control bar fades out after a few seconds of inactivity. These examples keep it visible at all times.

## Open Video UI

<Example src={useBaseUrl('/theoplayer/v11/examples/keep-control-bar-visible/demo.html')} />

Set `user-idle-timeout` to a negative value to disable idle detection, so the controls never fade out.

```html
<theoplayer-default-ui user-idle-timeout="-1">...</theoplayer-default-ui>
```

## Default UI

<Example src={useBaseUrl('/theoplayer/v11/examples/keep-control-bar-visible/default-ui.html')} exposeGlobals={false} />

In the [Default UI](../../ui/web/default-ui/index.mdx), override the fade-out transition with two CSS lines.

```css
.theo-secondary-color.vjs-control-bar {
  opacity: 1 !important;
  visibility: visible !important;
}
```
