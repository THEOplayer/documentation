With Open Video UI you compose a player from only the controls you need. This example uses a bare
`<theoplayer-ui>` element with a track info area in the top chrome and a control bar containing just
a play button, a seek bar, a time display, a mute button and a volume slider — no video area,
center play button or fullscreen button.

The video area is collapsed with CSS custom properties, so no `display: none` overrides are needed:

```css
theoplayer-ui {
  --theoplayer-aspect-ratio: none;
  --theoplayer-video-height: 0;
  --theoplayer-video-width: 0;
  --theoplayer-height: 6.5rem;
}
```

```html
<theoplayer-ui configuration="..." source="...">
  <div slot="top-chrome" class="track-info" no-auto-hide>...</div>
  <theoplayer-control-bar no-auto-hide>
    <theoplayer-play-button></theoplayer-play-button>
    <theoplayer-time-range></theoplayer-time-range>
    <theoplayer-time-display show-duration></theoplayer-time-display>
    <theoplayer-mute-button></theoplayer-mute-button>
    <theoplayer-volume-range></theoplayer-volume-range>
  </theoplayer-control-bar>
</theoplayer-ui>
```

`no-auto-hide` on the controls keeps them visible at all times instead of letting them
fade out when the player is idle, since there is no video to tap when the controls fade out.
