## Open Video UI

<ChangingUiWithCssDemo />

The accent color, range track, and control-bar gradient use CSS custom properties. The `::part()` selector styles the centered play button.
See the [Open Video UI styling example](https://optiview.dolby.com/docs/open-video-ui/web/examples/styling/) for more options.

```css
theoplayer-default-ui {
  --theoplayer-icon-color: #11cefe;
  --theoplayer-range-bar-color: #11cefe;
  --theoplayer-range-track-height: 6px;
  --theoplayer-control-background-gradient-stops: transparent 0%, rgb(0 0 0 / 85%) 100%;
}

theoplayer-default-ui::part(center-play-button) {
  outline: 2px solid #11cefe;
}
```
