[Millicast](pathname:///millicast/getting-started/) delivers real-time streaming with sub-second latency over WebRTC.
THEOplayer can subscribe to a Millicast stream directly: set the source `type` to `"millicast"` and
provide the stream name (`src`) and account identifier (`streamAccountId`).

```js
player.source = {
  sources: {
    type: 'millicast',
    src: 'multiview',
    streamAccountId: 'k9Mwad',
    // subscriberToken: '...' // for secure streams
  },
};
```

See the [`MillicastSource`](pathname:///theoplayer/v11/api-reference/web/interfaces/MillicastSource.html)
API reference for all available fields, including `subscriberToken` for secure streams.
