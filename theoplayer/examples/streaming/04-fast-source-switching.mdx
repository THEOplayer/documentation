# Fast source switching

Compare how long the player takes to start after changing the source.

import CodeBlock from '@theme/CodeBlock';
import FastSourceSwitchingDemo from '../_components/FastSourceSwitchingDemo';
import demoSource from '!!raw-loader!../../static/theoplayer/v11/examples/fast-source-switching/demo.html';

<FastSourceSwitchingDemo />

The player starts its initial source automatically and measures startup time from source assignment. When you load another source, the demo also measures time since that source was set. It ignores events from superseded switches.

```js
player.autoplay = true;

function loadSource(streamUrl) {
  player.source = {
    sources: { src: streamUrl, type: 'application/x-mpegurl' },
  };
}
```
