# Creating bookmarks

Select a bookmark to seek within the current stream or switch to another stream.

import CodeBlock from '@theme/CodeBlock';
import BookmarksDemo from './_components/BookmarksDemo';
import demoSource from '!!raw-loader!../static/theoplayer/v11/examples/bookmarks/demo.html';

<BookmarksDemo />

Each bookmark stores its title, source, poster, and playhead position. Selecting a bookmark saves the current position before seeking or loading the selected source.
Use the button below the player to add a bookmark at the current playhead.

```js
player.addEventListener(
  'loadedmetadata',
  () => {
    player.currentTime = bookmark.currentTime;
  },
  { once: true }
);
player.source = {
  sources: [{ src: bookmark.src, type: 'application/x-mpegurl' }],
  poster: bookmark.poster,
};
player.play();
```
