# Keeping track of time

Inspect the current playhead and the ranges that describe media playback.

import CodeBlock from '@theme/CodeBlock';
import KeepingTrackOfTimeDemo from './_components/KeepingTrackOfTimeDemo';

`TimeRanges` can contain zero or more intervals. Listen for playback and buffering events to keep a readout current.
See the [`TimeRanges` API](pathname:///theoplayer/v11/api-reference/web/interfaces/TimeRanges.html).

```js
function updateRanges() {
  console.log(player.currentTime, player.duration, player.played, player.buffered, player.seekable);
}

player.addEventListener(['timeupdate', 'progress', 'durationchange', 'seeking', 'seeked', 'play', 'pause'], updateRanges);
```
