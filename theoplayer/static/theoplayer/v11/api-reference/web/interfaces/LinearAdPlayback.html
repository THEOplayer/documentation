    Interface LinearAdPlaybackExperimental

    Playback state and controls for a linear ad in a client-side ad integration.

    The player reads these properties to report the ad playback state through its own API, and calls the methods when playback is controlled through the player. The integration must call ClientSideAdIntegrationController.updateLinearAdBreak whenever any of these properties change. Report playback errors with ClientSideAdIntegrationController.error for non-fatal aderror events or ClientSideAdIntegrationController.fatalError for fatal errors.

    ClientSideAdIntegrationController.linearAdPlayer implements this interface. A forwarding wrapper around it behaves identically when it forwards the built-in player's events to ClientSideAdIntegrationController.updateLinearAdBreak.

    Readonly ExperimentalreadyState

    readyState: number

    The ready state of the linear ad, using the same values and meaning as ChromelessPlayer.readyState.

    A delegate backed by an HTMLMediaElement can forward its readyState.

    Remarks

    The player reads this property when ClientSideAdIntegrationController.updateLinearAdBreak is called.

    Optional Readonly ExperimentalusesContentVideoElement

    usesContentVideoElement?: boolean

    Whether this playback really renders the linear ad in ClientSideAdIntegrationController.contentVideoElement instead of ClientSideAdIntegrationController.adContainer.

    Set this to true only when this playback plays the ad in the content video element, so the player can hand over the element before the ad starts and restore the content afterwards. The player reads this property once, when ClientSideAdIntegrationController.startLinearAdBreak is called.

    Remarks

    • Must be false or omitted when ClientSideAdIntegrationController.contentVideoElement is undefined.
    • ClientSideAdIntegrationController.linearAdPlayer returns false. A wrapper around it must also return false.

    Default Value

    false
