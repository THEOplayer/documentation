    Interface ClientSideAdIntegrationControllerExperimental

    The controller for a custom client-side ad integration.

    Besides the common CustomAdIntegrationController operations, it allows the integration to pause the content and play linear ads, either on its own or through the built-in player.

    Readonly ExperimentaladContainer

    adContainer: HTMLElement

    A DOM element for rendering ads, owned by this integration.

    The element is absolutely positioned over the player's video area (position: absolute; inset: 0), on top of the content video. It is initially empty and does not receive pointer events. The integration may add child elements to render non-linear ads, or to play linear ads with its own ad player (see LinearAdPlayback). It may style this element during a linear ad break; the player resets its styles when the break ends or when a new source is set during an active break.

    Remarks

    • The element is removed when the player is destroyed.
    • The size of the player's video area is dictated by contentElement, or by the ClientSideAdIntegrationController.linearAdPlayer element while the built-in player plays a linear ad. This element always follows that size.
    • The player stacks its elements in this order, from back to front: contentElement, the ClientSideAdIntegrationController.linearAdPlayer element, adContainer.

    Readonly ExperimentalcontentElement

    contentElement: HTMLElement

    The DOM element in which the content is rendered, owned by the player.

    The element is positioned in the normal flow of the player's DOM (position: relative), so it dictates the size of the player's video area. It always contains contentVideoElement, if that is defined. During a linear ad break, the integration may style this element to create custom ad layouts, for example to scale the content down into a corner while an ad is shown in adContainer. The player resets its styles when the break ends.

    Remarks

    • The integration must not add, remove or replace child elements.
    • If a new source is set while a linear ad break is active, the player resets these styles before CustomAdIntegrationHandler.resetSource is called.
    • Unless StartLinearAdBreakOptions.keepContentPlaying is set, the player hides this element with visibility: hidden during a linear ad break, except when the playback sets LinearAdPlayback.usesContentVideoElement. It remains in the normal flow and dictates the size of the player's video area.
    • The shared linear ad player element replaces this element in the normal flow, or is shown over it when StartLinearAdBreakOptions.keepContentPlaying is set.

    Readonly ExperimentalcontentVideoElement

    contentVideoElement: HTMLVideoElement | undefined

    The video element in which the content is played.

    On some platforms, a linear ad must be played in the same video element as the content, for example to keep native fullscreen playback on iOS. In that case, play the linear ad in this element (for example by passing it to a third-party ad SDK), and set LinearAdPlayback.usesContentVideoElement when starting linear ad playback.

    Remarks

    • This is undefined when the player can't let ad integrations reuse the content's video element for linear ad playback, for example when the content is rendered into multiple media elements or outside of the DOM. Play linear ads in adContainer instead.
    • When defined, this is a descendant of contentElement.
    • The integration may only change the element's source or playback state during linear ad playback, after startLinearAdBreak was called with LinearAdPlayback.usesContentVideoElement set.
    • The element may change when a new source is set. Read it when starting each linear ad break rather than caching it.

    endAdBreak

    • endAdBreak(adBreak: AdBreak): void
      Experimental

      End the given ad break.

      An ad break begins implicitly when the first of its ads is begun.

      Parameters

      • adBreak: AdBreak

        The ad break to be ended.

      Returns void

      Remarks

      • Any of its ads that are still playing will first be ended.
      • An AdsEventMap.adbreakend event and an AdsEventMap.adbreakchange event will be fired.
      • The ad break stays in adBreaks, but is removed from Ads.scheduledAdBreaks. Its ads that were not begun stay in Ads.scheduledAds.
      • To remove the ad break, call removeAdBreak afterwards. This does not end the ad break again.
      • If one of its remaining ads is begun later, the ad break begins again and is added back to Ads.scheduledAdBreaks.
      • If the ad break is not currently playing, this does nothing.

    startLinearAdBreak

    • startLinearAdBreak(options?: StartLinearAdBreakOptions): void
      Experimental

      Start a linear ad break.

      The player pauses the content and hides it (unless the ad is played in the content video element or StartLinearAdBreakOptions.keepContentPlaying is set, see contentElement for how it is hidden), and reports ad playback through its own API by default. StartLinearAdBreakOptions.timeline can route time-related state to the content, while StartLinearAdBreakOptions.audio can route volume and mute state to the content.

      Parameters

      • Optionaloptions: StartLinearAdBreakOptions

        Options for the linear ad break. If StartLinearAdBreakOptions.playback is omitted, the integration can load an ad with linearAdPlayer.

      Returns void

      Remarks

      • CustomAdIntegrationController.content keeps reflecting the state of the content: paused at the interrupted position, or still playing if StartLinearAdBreakOptions.keepContentPlaying is set.
      • If LinearAdPlayback.usesContentVideoElement is set, the content stays visible and the player releases contentVideoElement to the integration. It restores the content source and position when endLinearAdBreak is called.
      • Use CustomAdIntegrationController.beginAd, CustomAdIntegrationController.updateAdProgress and CustomAdIntegrationController.endAd to report the individual ads during linear ad playback.

      Throws

      Error If a linear ad break was already started.

    • updateLinearAdBreak(): void
      Experimental

      Notify the player that the state of the LinearAdPlayback passed to startLinearAdBreak has changed.
