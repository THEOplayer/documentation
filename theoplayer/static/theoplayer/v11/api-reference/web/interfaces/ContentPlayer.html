    Interface ContentPlayerExperimental

    Playback state and controls for the content, independent of linear ad playback.

    These controls always act directly on the content player and bypass the ad player.

    Remarks

    Mutating members throw while the content video element is used for linear ad playback, or after the integration is destroyed.

    Readonly ExperimentalcurrentProgramDateTime

    currentProgramDateTime: Date | null

    The current playback position of the content, as a timestamp, or null if the content does not have program date time information.

    Remarks

    • The relation between currentProgramDateTime and currentTime is determined by the manifest.

    Inherited from ContentPlayer.currentProgramDateTime

    ExperimentalcurrentTime

    currentTime: number

    The current content position, in seconds.

    Setting this seeks the content to the requested position, clamped to ReadonlyContentPlayer.seekable. The write is a no-op when the content has no seekable range.

    Throws

    Error If the content video element is used for linear ad playback, or the integration has been destroyed.

    Overrides ReadonlyContentPlayer.currentTime

    Experimentalmuted

    muted: boolean

    Whether the content audio is muted. This changes the content only.

    At break end, the viewer's mute state is copied back to the content, unless StartLinearAdBreakOptions.audio is 'content', in which case the viewer's mute control already applies to the content.

    Throws

    Error If the content video element is used for linear ad playback, or the integration has been destroyed.

    Overrides ReadonlyContentPlayer.muted
