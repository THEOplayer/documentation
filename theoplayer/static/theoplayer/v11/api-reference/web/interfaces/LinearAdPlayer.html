    Interface LinearAdPlayerExperimental

    The built-in linear ad player shared by client-side ad integrations for one player.

    It can be used during or outside a linear ad break. Its playback state is reported through the player's API only when it is used directly, or through a forwarding wrapper, as the break's StartLinearAdBreakOptions.playback.

    Readonly Experimentalelement

    element: HTMLElement

    The shared DOM element used to play linear ads.

    This element is a sibling of ClientSideAdIntegrationController.contentElement. During a linear ad break that does not use LinearAdPlayback.usesContentVideoElement, it replaces the hidden content element in the normal flow, or is shown over the content when StartLinearAdBreakOptions.keepContentPlaying is set.

    The integration may style this element freely during a break, for example to show the ad next to the content.

    Remarks

    • The integration must not add, remove or replace child elements.
    • The player restores the element's styles when the break ends, when a new source is set during an active break, or when the player is destroyed.
    • This element is not used by a playback that sets LinearAdPlayback.usesContentVideoElement.

    Optional Readonly ExperimentalusesContentVideoElement

    usesContentVideoElement?: boolean

    Whether this playback really renders the linear ad in ClientSideAdIntegrationController.contentVideoElement instead of ClientSideAdIntegrationController.adContainer.

    Set this to true only when this playback plays the ad in the content video element, so the player can hand over the element before the ad starts and restore the content afterwards. The player reads this property once, when ClientSideAdIntegrationController.startLinearAdBreak is called.

    Remarks

    • Must be false or omitted when ClientSideAdIntegrationController.contentVideoElement is undefined.
    • ClientSideAdIntegrationController.linearAdPlayer returns false. A wrapper around it must also return false.

    load

    • load(source: string | TypedSource, ad?: Ad): Promise<void>
      Experimental

      Load and play a linear ad source through the built-in player.

      The source may contain a single ad or a whole ad break with multiple ads. If ad is given, the source contains only that ad and the player reports its lifecycle through CustomAdIntegrationController.beginAd, CustomAdIntegrationController.updateAdProgress and CustomAdIntegrationController.endAd, and updates Ad.duration if not yet known. If ad is omitted, the integration must report the ads in the source itself, for example based on timed metadata and CustomAdIntegrationController.content.

      If a third-party playback delegate is active for the break, this method still loads and plays the source through the built-in player, but the player's API continues to report the active delegate's state.

      Parameters

      • source: string | TypedSource

        The media to play, e.g. an MP4 or HLS file.

      • Optionalad: Ad

        The single ad in the source, if any. It must be created through CustomAdIntegrationController.createAd with type 'linear'.

      Returns Promise<void>

      A promise that resolves when the source has ended or playback was stopped, or rejects if the source could not be played. In the latter case, the player also fires an aderror event.

      Remarks

      • This works during or outside a linear ad break. An ad can only be supplied during a break.
      • Sources can be played back-to-back by calling this method again after the returned promise resolves.
      • If the source was preloaded with preload using exactly the same source, the preloaded data is used. Otherwise, the preload is discarded and the source is loaded normally.
      • Playback is stopped when stop or ClientSideAdIntegrationController.endLinearAdBreak is called. If ad is given, playback is also stopped when Ads.skip is called (unless overridden by ClientSideAdIntegrationHandler.skipAd) or when the integration calls CustomAdIntegrationController.skipAd, CustomAdIntegrationController.endAd or CustomAdIntegrationController.removeAd for that ad.

      Throws

      Error If ad is given outside a linear ad break, or another built-in source is currently playing.

    preload

    • preload(source: string | TypedSource): Promise<void>
      Experimental

      Preload a linear ad source through the built-in player.

      The built-in player starts loading the source in the background, while the content keeps playing. A later call to load with exactly the same source starts faster.

      Parameters

      • source: string | TypedSource

        The media to preload, e.g. an MP4 or HLS file.

      Returns Promise<void>

      A promise that resolves when enough of the source is loaded to start playback, or rejects if the source could not be preloaded. In the latter case, no aderror event is fired.

      Remarks

      • This works during or outside a linear ad break.
      • Only one source is preloaded at a time. Preloading a different source discards the previous preload.
      • The built-in player has a single video element, so preloading is not possible while it is playing a linear ad. The returned promise then rejects.
      • The preload is discarded when a different source is played, when the preloaded source has been played, or when a new source is set on the player.
      • Preloading is best effort. If it fails, load still loads the source normally.

    stop

    • stop(): void
      Experimental

      Stop the source currently playing through the built-in player.

      The built-in player stops and unloads the source started with load, and the promise returned by that call resolves. A linear ad break stays active, so the integration can load another source or end the break.

      Use this to skip an ad in ClientSideAdIntegrationHandler.skipAd, or to exit an ad early.

      Returns void

      Remarks

      • This works during or outside a linear ad break.
      • If ad was given to load, the player ends that ad. Otherwise, the integration must end the ads it reported itself.
      • This has no effect if no source is currently playing through the built-in player.
