      • startLinearAdBreak

         abstract Unit startLinearAdBreak(StartLinearAdBreakOptions options)

        Starts a linear ad break owned by this integration.

        The content is paused and hidden by default. Set StartLinearAdBreakOptions.keepContentPlaying to keep it visible and playing. With CUSTOM content, the built-in linear ad player can render into the app's surface; content may continue playing but will not be visible while that player owns the surface. Integration-owned players do not receive the content surface.

        Parameters:
        options - playback and routing options for the break

      • updateLinearAdBreak

      • getContentView

         abstract View getContentView()

        Stable host view containing the content player.

        During a linear break, only scaleX, scaleY, translationX, translationY, pivotX, pivotY, alpha, visibility and clipBounds may be changed. Never add or remove children, reparent this view, or change its layout parameters. The player snapshots these properties at break start and restores them on end, source reset and destroy.

      • getContentRenderingTarget

         abstract RenderingTarget getContentRenderingTarget()

        Rendering target used by the content player.

        TEXTURE_VIEW is transformable. SURFACE_VIEW is not reliably transformable, and SURFACE_CONTROL is available only on API 29 and later. CUSTOM means the app supplied the rendering surface directly, so this view does not contain the rendered video.

      • getLinearAdPlayer

         abstract LinearAdPlayer getLinearAdPlayer()

        The built-in player for linear ads.

        An integration may load an ad only while it owns a break started with playback = null.

      • getAdContainer

         abstract ViewGroup getAdContainer()

        Transparent container for this integration's ad UI, following the video area.

        The integration may add and remove its own children. The container is non-clickable and non-focusable while empty, and is removed when the player is destroyed. Reset the container's own properties after a break; its children remain integration-owned. Use a TextureView, or call SurfaceView.setZOrderMediaOverlay(true) on an integration-owned SurfaceView.
