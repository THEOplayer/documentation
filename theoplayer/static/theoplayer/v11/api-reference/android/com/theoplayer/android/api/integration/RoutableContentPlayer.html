Interface RoutableContentPlayer

  • All Implemented Interfaces:
    com.theoplayer.android.api.event.EventDispatcher , com.theoplayer.android.api.player.ContentPlayer , com.theoplayer.android.api.player.ReadonlyContentPlayer 
    @MainThread()@ApiStatus.Experimental() 
public interface RoutableContentPlayer
 implements ContentPlayer

    The content player as seen by a routable integration: the ContentPlayer of a custom ad integration, plus the state and the source control an integration needs.

    • It bypasses the integration's own hooks: currentTime, play(), ... always act on the content.

    • It dispatches the content's player events, before they pass through RoutableIntegrationHandler.onEvent.

      • setSource

         abstract Boolean setSource(SourceDescription source)

        Loads a source in the content without changing the source of the player as the application sees it.

        • com.theoplayer.android.api.player.Player.getSource keeps returning the application's source, and the application does not receive the resulting sourcechange and currentsourcechange events.

        • The application setting a new source ends the override.

        Returns:

        true once the source is loaded, false when the change was superseded by another source change.

      • restoreSource

         abstract Boolean restoreSource()

        Reloads the source the content played before setSource: the source RoutableIntegrationHandler.setSource returned for the application's source, or the application's source itself when it was not rewritten.

        The source is loaded from its start: the position and the paused state of the content before setSource are not restored. Set currentTime and call play once this returns to continue where the content was.

        Returns:

        true once the source is loaded, or when there was nothing to restore; false when the change was superseded by another source change or the integration is destroyed.
