Package com.theoplayer.android.api.integration

Interface RoutableIntegrationHandler

  • All Implemented Interfaces:
    com.theoplayer.android.api.ads.CustomAdIntegrationHandler 
    @MainThread()@ApiStatus.Experimental() 
public interface RoutableIntegrationHandler
 implements CustomAdIntegrationHandler

    The integration API the player calls, returned by a RoutableIntegrationFactory.

    Hooks

    Each hook takes over the corresponding public player operation. A hook that returns null (for a getter) or false (for a command) leaves the operation to the content. The RoutableIntegrationController.content always bypasses the hooks.

    The getters are called often, and already at registration before any source is set: keep them cheap and callable at any time.

    While the integration takes over playback, the content's events no longer describe the player. The integration then dispatches play, playing, pause, timeupdate and durationchange itself through RoutableIntegrationController.dispatchEvent.

    Errors

    An exception thrown by a hook, by onEvent or by setSource, resetSource or destroy is a fatal player error with code com.theoplayer.android.api.error.ErrorCode.MEDIA_INTERNAL_ERROR. An exception thrown by skipAd or scheduleAd is a non-fatal ad error.

    Lifecycle

    setSource, resetSource and destroy have the shape of CustomAdIntegrationHandler. The integration lives as long as the player: there is no public API to remove it, and destroy is called when the player is destroyed. When destroy is called during an ad, the player ends the ad and its ad break and then removes the integration's ad breaks. It does not resume the content.
