      • getEnablePauseAds

         final Boolean getEnablePauseAds()

        Whether Google DAI pause ads are enabled.

        • When enabled, the IMA SDK can show a pause ad on top of the player while a Google DAI stream is paused, if the publisher configured pause ads in Google Ad Manager.

        • This only applies to the Google DAI integration (GoogleDaiIntegration).

        Default: false.

      • getPauseAdDelayMs

         final Long getPauseAdDelayMs()

        The additional delay, in milliseconds, between the player pausing and the IMA SDK being told about the pause, so that a Google DAI pause ad can be shown.

        • The IMA SDK adds its own delay of about one second before it shows the pause ad.

        • This only applies when enablePauseAds is true, and only to pauses outside of an ad break.

        • When set to 0, the pause is forwarded to the IMA SDK immediately.

        • The IMA SDK only learns about a pause after this delay: pauses shorter than the delay are never reported to it, and its own pause/resume timing is shifted by the delay. Ad tracking inside ad breaks is unaffected.

        Default: 0.
