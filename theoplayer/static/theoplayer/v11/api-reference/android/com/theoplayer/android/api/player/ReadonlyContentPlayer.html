Package com.theoplayer.android.api.player

Interface ReadonlyContentPlayer

  • All Implemented Interfaces:
    com.theoplayer.android.api.event.EventDispatcher 
    @ApiStatus.Experimental() 
public interface ReadonlyContentPlayer
 implements EventDispatcher<PlayerEvent<?>>

    Read-only playback state for the content player.

    For a server-side integration, this is the state of the stitched stream, including ads. For a client-side integration, it is the state of the content only and is not affected by linear ads from any integration. While a linear ad plays, content remains paused at the position where it was interrupted.

    Events from the content player are forwarded, including PlayerEventTypes.PLAY, PlayerEventTypes.PAUSE, PlayerEventTypes.PLAYING, PlayerEventTypes.SEEKING, PlayerEventTypes.SEEKED, PlayerEventTypes.TIMEUPDATE, PlayerEventTypes.DURATIONCHANGE, PlayerEventTypes.READYSTATECHANGE, PlayerEventTypes.WAITING, PlayerEventTypes.LOADEDMETADATA, PlayerEventTypes.LOADEDDATA, PlayerEventTypes.ERROR, PlayerEventTypes.VOLUMECHANGE, PlayerEventTypes.RATECHANGE, PlayerEventTypes.ENDED, and PlayerEventTypes.RESIZE.
