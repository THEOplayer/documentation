Package com.theoplayer.android.api.player

Interface ContentPlayer

  • All Implemented Interfaces:
    com.theoplayer.android.api.event.EventDispatcher , com.theoplayer.android.api.player.ReadonlyContentPlayer 
    @ApiStatus.Experimental() 
public interface ContentPlayer
 implements ReadonlyContentPlayer

    Playback state and controls for content, independent of linear ad playback.

    Mutating members control the content and do not change the routed player's state. They throw IllegalStateException after the integration is destroyed.
