# Errors on Web

import Intro from '../../../shared/miscellaneous/_error-introduction-intro.mdx';

<Intro />

When a fatal playback issue occurs, THEOplayer's default UI overlays an error message on top of the video player.
This error message indicates to the viewer that playback is unsuccessful.
