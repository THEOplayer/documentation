# How to disable the right click on Web

There are two ways to disable the right-click menu on the player.

## Disable the context menu feature

By default, the `contextmenu` feature is included in the Web SDK.
If you build your SDK with this feature disabled, your player does not have a context menu.

## Add a CSS rule to your page

If you do not want to rebuild your player, you can add the following CSS rule after including THEOplayer's `ui.css`.
You can add this rule in a `<style>` element (see below) or in an external stylesheet.

```html
<link rel="stylesheet" type="text/css" href="/path/to/ui.css" />

<style>
  .theo-context-menu {
    display: none;
  }
</style>
```
