## Usage

You need to set up [THEOplayer Conviva Connector for Web](https://github.com/THEOplayer/web-connectors/tree/main/conviva).
Please refer to [this](/theoplayer/connectors/web/conviva/) section to learn all about how to integrate and use the Conviva connector on Web SDK.

If you have a Yospace SSAI stream and want to report ad related events to Conviva as well, the connector documentation also describes how to [combine it with the Yospace connector](/theoplayer/connectors/web/conviva/getting-started/#usage-with-yospace-connector).
