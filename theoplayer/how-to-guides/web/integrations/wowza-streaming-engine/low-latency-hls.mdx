## Configure THEOplayer to play your LL-HLS stream

1. Set up a basic HTML file and include the THEOplayer library.
   See "[Getting started on Web](/theoplayer/getting-started/sdks/web/getting-started/)".
2. Specify the LL-HLS stream generated above as the `src` of your source configuration.
3. Set `lowLatency` to `true` on that source.

```js
player.source = {
  sources: [
    {
      src: 'https://5d6e17f1ca731.streamlock.net/LowLatencyBBB/myStream/playlist.m3u8',
      type: 'application/x-mpegurl',
      lowLatency: true,
    },
  ],
};
```
