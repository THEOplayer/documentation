# Clear Key on Web

import Intro from '../../shared/drm/_clear-key-intro.mdx';

<Intro />

Head to our page on [DRM](./introduction.mdx) for more general information.

Please check also our related [API documentation](pathname:///theoplayer/v11/api-reference/web/interfaces/ClearkeyKeySystemConfiguration.html) on how to set these.

## Code example

With keys:

```js
player.source = {
  sources: {
    src: 'your-manifest-URL',
    useCredentials: false,
    contentProtection: {
      clearkey: {
        keys: [
          {
            id: 'id',
            value: 'value',
          },
        ],
      },
    },
  },
};
```

With a license URL:

```js
player.source = {
  sources: {
    src: 'https://storage.googleapis.com/shaka-demo-assets/angel-one-clearkey/dash.mpd',
    useCredentials: false,
    contentProtection: {
      clearkey: {
        licenseAcquisitionURL: 'https://cwip-shaka-proxy.appspot.com/clearkey?_u3wDe7erb7v8Lqt8A3QDQ=ABEiM0RVZneImaq7zN3u_w',
      },
    },
  },
};
```
