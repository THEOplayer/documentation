# How to programmatically detect audio tracks on Web

import Intro from '../../shared/media-tracks/_detect-audio-tracks-intro.mdx';

<Intro />

## Usage

Listen for the [`addtrack`](pathname:///theoplayer/v11/api-reference/web/interfaces/TrackListEventMap.html#addtrack) event
on [`player.audioTracks`](pathname:///theoplayer/v11/api-reference/web/classes/ChromelessPlayer.html#audiotracks)
to detect every [`MediaTrack`](pathname:///theoplayer/v11/api-reference/web/interfaces/MediaTrack.html) that is added to the player.

```js
function handleAddTrackEvent(addTrackEvent) {
  const audioTrack = addTrackEvent.track;
}
player.audioTracks.addEventListener('addtrack', handleAddTrackEvent);
```
