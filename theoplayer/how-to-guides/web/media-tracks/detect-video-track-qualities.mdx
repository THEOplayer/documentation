# How to programmatically detect video track qualities on Web

import Intro from '../../shared/media-tracks/_detect-video-track-qualities-intro.mdx';

<Intro />

## Usage

The [`qualities`](pathname:///theoplayer/v11/api-reference/web/interfaces/MediaTrack.html#qualities) of a video track
are available as soon as the track is added to [`player.videoTracks`](pathname:///theoplayer/v11/api-reference/web/classes/ChromelessPlayer.html#videotracks).

```js
function handleAddTrackEvent(addTrackEvent) {
  const videoTrackQualities = addTrackEvent.track.qualities;
}
player.videoTracks.addEventListener('addtrack', handleAddTrackEvent);
```
