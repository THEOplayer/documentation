## 1. Lower the target buffer

<TargetBuffer />

To set the target buffer length in seconds, use the [`targetBuffer`](pathname:///theoplayer/v11/api-reference/web/interfaces/ABRConfiguration.html#targetbuffer)
property of the [ABR API](pathname:///theoplayer/v11/api-reference/web/interfaces/ABRConfiguration.html):

```js
player.abr.targetBuffer = 6;
```

If necessary to have a different target buffer length for mobile, add a check like this:

```js
if (THEOplayer.videojs.browser.IS_ANDROID || THEOplayer.videojs.browser.IS_IOS) {
  player.abr.targetBuffer = 8;
}
```

This snippet leverages THEOplayer's Video.js component.

## 2. Manage preloading

<Preloading />

```js
player.preload = 'auto'; // "metadata" is also a valid value
```

## 3. Choose the renditions considered for ABR

<Renditions />

You can also configure the
[`restrictToPlayerSize`](pathname:///theoplayer/v11/api-reference/web/interfaces/SourceAbrConfiguration.html#restrictToPlayerSize)
property of the source's ABR configuration to replicate the mobile behaviour on laptop and desktop browsers.

See [how to programmatically select a video track quality](./select-video-track-quality.mdx)
to learn how to set the [`targetQuality`](pathname:///theoplayer/v11/api-reference/web/interfaces/MediaTrack.html#targetquality) of a video track.
