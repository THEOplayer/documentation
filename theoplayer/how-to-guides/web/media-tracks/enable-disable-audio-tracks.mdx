# How to programmatically enable or disable audio tracks on Web

import Intro from '../../shared/media-tracks/_enable-disable-audio-tracks-intro.mdx';

<Intro />

## Usage

The Web SDK exposes the audio tracks through [`player.audioTracks`](pathname:///theoplayer/v11/api-reference/web/classes/ChromelessPlayer.html#audiotracks),
which contains [`MediaTrack`](pathname:///theoplayer/v11/api-reference/web/interfaces/MediaTrack.html) objects with an
[`enabled`](pathname:///theoplayer/v11/api-reference/web/interfaces/MediaTrack.html#enabled) property.

```js
// enable a specific audio track
player.audioTracks[indexOfRequestedAudioTrack].enabled = true;
```
