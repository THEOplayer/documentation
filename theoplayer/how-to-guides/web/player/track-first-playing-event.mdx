# How to track the first play(ing) event on Web

import Intro from '../../shared/player/_track-first-playing-event-intro.mdx';

<Intro />

## Usage

```js
function firstPlayingHandler(event) {
  player.removeEventListener('playing', firstPlayingHandler);
  console.log('First playing event!', event);
}

player.addEventListener('sourcechange', () => {
  player.removeEventListener('playing', firstPlayingHandler);
  player.addEventListener('playing', firstPlayingHandler);
});
```

Instead of `sourcechange`, you can also listen for `loadedmetadata`, which is dispatched once the player
has loaded the metadata of the new stream.
