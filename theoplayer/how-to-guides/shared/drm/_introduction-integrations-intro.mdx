These DRM vendors are supported through an integration. An integration is not part of the SDK: it is added on top of it
as a [custom DRM integration](#custom-integration), for which ready-made examples are available in the
[DRM integration samples repository](https://github.com/THEOplayer/samples-drm-integration). Vendors which don't require
custom license or certificate requests can be used with a plain key system configuration instead.
