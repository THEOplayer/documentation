These DRM vendors can be used through an integration. An integration is not part of the SDK: it is added on top of it as
a [custom DRM integration](#custom-integration). Ready-made integrations for many vendors are available in the
[DRM integration samples repository](https://github.com/THEOplayer/samples-drm-integration). Vendors which don't require
custom license or certificate requests can be used with a plain key system configuration instead.
