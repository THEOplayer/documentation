THEOplayer offers support for Google IMA as an ad integration system.
Users of Google Ad Manager (formerly known as DoubleClick for Publishers) should use this ad integration.

Scheduling and tracking ads through the Google IMA ad integration is similar to the default ad integration.
The main difference is that you need to indicate through the API
that you want to use Google IMA as the ad integration, and that you need to include the Google IMA SDK.
