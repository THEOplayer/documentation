Wowza Streaming Engine™ media server software can deliver Low-Latency HLS (LL-HLS) live streams,
which THEOplayer can play back on every platform.

Low-Latency HLS streams conform to
[Apple's protocol extension to the HLS specification](https://developer.apple.com/documentation/http-live-streaming/enabling-low-latency-http-live-streaming-hls).
