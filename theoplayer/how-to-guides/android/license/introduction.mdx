# License on Android

## Passing the license through the player configuration

Include the license in the player configuration, either by passing the license as a string
or by passing a license URL:

```kotlin
// passing the license as a string
val playerConfig = THEOplayerConfig.Builder()
    .license("your_license_here")
    .build()
```

```kotlin
// passing the license as a URL
val playerConfig = THEOplayerConfig.Builder()
    .licenseUrl("your_licenseUrl_here")
    .build()
```

## Passing the license through the manifest

Define the same `license` or `licenseUrl` as a new key in the app's manifest.

The Android SDK allows configuring the license through metadata keys,
which can be either `THEOPLAYER_LICENSE` or `THEOPLAYER_LICENSE_URL`.

- `THEOPLAYER_LICENSE` must be a license string
- `THEOPLAYER_LICENSE_URL` must be a valid URL to a license server

The license defined in the player configuration has higher precedence than the license provided in the app's manifest.
If neither of these are defined, then the player will throw a license error.
