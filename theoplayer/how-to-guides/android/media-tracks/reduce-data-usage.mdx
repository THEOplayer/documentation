## 1. Lower the target buffer

<TargetBuffer />

Use the [`targetBuffer`](<pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/abr/Abr.html#setTargetBuffer(int)>)
property of the [ABR API](pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/abr/Abr.html) to set it to 6 seconds:

```kotlin
player.abr.targetBuffer = 6
```

## 2. Manage preloading

<Preloading />

```kotlin
player.preload = PreloadType.AUTO
```

## 3. Choose the renditions considered for ABR

<Renditions />

See [how to programmatically select a video track quality](./select-video-track-quality.mdx) to learn how to set the
[`targetQuality`](<pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/player/track/mediatrack/MediaTrack.html#setTargetQuality(Q)>)
of a video track.
