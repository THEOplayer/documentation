# How to programmatically detect video track quality changes on Android

import Intro from '../../shared/media-tracks/_detect-video-track-quality-changes-intro.mdx';

<Intro />

## Usage

Listen for the [`ACTIVEQUALITYCHANGEDEVENT`](pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/event/track/mediatrack/video/VideoTrackEventTypes.html#ACTIVEQUALITYCHANGEDEVENT)
event of a [`MediaTrack`](pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/player/track/mediatrack/MediaTrack.html).

```kotlin
// detect video tracks being added to the player
player.videoTracks.addEventListener(VideoTrackListEventTypes.ADDTRACK) { addTrackEvent ->
    // detect quality changes of a track
    addTrackEvent.track.addEventListener(VideoTrackEventTypes.ACTIVEQUALITYCHANGEDEVENT) { event ->
        println("activequalitychanged event detected! ${event.quality}")
    }
}
```
