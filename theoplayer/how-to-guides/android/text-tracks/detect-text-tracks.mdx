# How to programmatically detect text tracks on Android

import Intro from '../../shared/text-tracks/_detect-text-tracks-intro.mdx';

<Intro />

## Usage

Listen for the [`ADDTRACK`](pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/event/track/texttrack/list/TextTrackListEventTypes.html#ADDTRACK)
event on [`player.getTextTracks()`](<pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/player/Player.html#getTextTracks()>)
to detect every [`TextTrack`](pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/player/track/texttrack/TextTrack.html) that is added to the player.

```kotlin
player.textTracks.addEventListener(TextTrackListEventTypes.ADDTRACK) { addTrackEvent ->
    val textTrack = addTrackEvent.track
}
```
