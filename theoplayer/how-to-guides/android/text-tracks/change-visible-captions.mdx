# How to dynamically change the visible captions on Android

import Intro from '../../shared/text-tracks/_change-visible-captions-intro.mdx';

<Intro />

## Usage

The function below disables all text tracks which are currently active,
and then enables the text track with the requested language.

```kotlin
fun setLanguage(player: Player, language: String) {
    for (textTrack in player.textTracks) {
        textTrack.mode = if (textTrack.language == language) {
            TextTrackMode.SHOWING
        } else {
            TextTrackMode.DISABLED
        }
    }
}
```
