# How to insert subtitles on Android

import Intro from '../../shared/text-tracks/_insert-subtitles-intro.mdx';

<Intro />

## Usage

Each text track is described by a [`TextTrackDescription`](pathname:///theoplayer/v11/api-reference/android/com/theoplayer/android/api/source/TextTrackDescription.html).

```kotlin
val sourceWithSubs = SourceDescription.Builder("//path/to/your-manifest.m3u8")
    .textTracks(
        TextTrackDescription.Builder("path/to/your-subs-track1.vtt")
            .isDefault(true)
            .kind(TextTrackKind.SUBTITLES)
            .srclang("en")
            .label("English subs")
            .build()
    )
    .build()
```
