## Configuring THEOplayer

The Android SDK plays the key system that is available on the device: Widevine on all Android devices, and PlayReady
on devices which support it (such as Android TV). Configure a license acquisition URL for each of these key systems:

```java
DRMConfiguration drmConfiguration = new DRMConfiguration.Builder()
    .widevine(
        new KeySystemConfiguration.Builder("https://widevine-server.com/license").build()
    )
    .playready(
        new KeySystemConfiguration.Builder("https://playready-server.com/license").build()
    )
    .build();
TypedSource typedSource = new TypedSource.Builder("https://yourdomain.com/playlist.m3u8")
    .type(SourceType.HLS)
    .drm(drmConfiguration)
    .build();
SourceDescription sourceDescription = new SourceDescription.Builder(typedSource)
    .build();
theoplayer.getPlayer().setSource(sourceDescription);
```

The `#EXT-X-KEY` tags of the other key systems are ignored.
