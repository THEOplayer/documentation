## Configure THEOplayer to play your LL-HLS stream

1. Set up a basic app with THEOplayer.
   See "[Getting started on iOS](/theoplayer/getting-started/sdks/ios/getting-started/)".
2. Specify the LL-HLS stream generated above as the `src` of your typed source.

On iOS and tvOS, HLS streams are played back by the operating system,
which handles Low-Latency HLS without any additional configuration.

```swift
let source = SourceDescription(
    source: TypedSource(
        src: "https://5d6e17f1ca731.streamlock.net/LowLatencyBBB/myStream/playlist.m3u8",
        type: "application/x-mpegurl"
    )
)

theoplayer.source = source
```
