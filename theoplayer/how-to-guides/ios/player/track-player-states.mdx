## Implementation

<Events />

The snippet below demonstrates how you can track some of the related events through the iOS SDK.
All other events can be tracked similarly. You can find the event names in
[the `PlayerEventTypes` API reference](pathname:///theoplayer/v11/api-reference/ios/Structs/PlayerEventTypes.html),
and the properties of the player in
[the `THEOplayer` API reference](pathname:///theoplayer/v11/api-reference/ios/Classes/THEOplayer.html).
This approach is valid for all iOS-based platforms, including iPadOS and tvOS.

```swift
player.addEventListener(type: PlayerEventTypes.SOURCE_CHANGE) { event in
    print(event)
}
// ...
player.addEventListener(type: PlayerEventTypes.ENDED) { event in
    print(event)
}
```
