# How to programmatically detect text tracks on iOS

import Intro from '../../shared/text-tracks/_detect-text-tracks-intro.mdx';

<Intro />

## Usage

Listen for the [`ADD_TRACK`](pathname:///theoplayer/v11/api-reference/ios/Structs/TextTrackListEventTypes.html) event
on [`player.textTracks`](pathname:///theoplayer/v11/api-reference/ios/Classes/THEOplayer.html#/s:13THEOplayerSDK0A0C10textTracksAA13TextTrackList_pvp)
to detect every [`TextTrack`](pathname:///theoplayer/v11/api-reference/ios/Protocols/TextTrack.html) that is added to the player.

```swift
self.player.textTracks.addEventListener(type: TextTrackListEventTypes.ADD_TRACK, listener: { addTrackEvent in
    let textTrack = addTrackEvent.track
})
```
