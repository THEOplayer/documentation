# Uplynk on iOS

import Intro from '../../shared/drm/_uplynk-intro.mdx';
import Resources from '../../shared/drm/_uplynk-resources.mdx';
import IntegrationIntro from '../../shared/drm/_integration-intro.mdx';

<Intro />

**Important:** Uplynk customers should configure DRM through the [THEOplayer Uplynk connector for iOS](../../../external/iOS-Connector/Code/Uplynk/docs/preplay.md).
(The Uplynk connector provides an out-of-the-box integration with Uplynk's Preplay, Ping and Asset Info services,
exposes additional APIs, and enhances your UI and UX.)

Head to our page on [DRM](./introduction.mdx) for more general information.

## Integration

<IntegrationIntro />

The [Uplynk connector for iOS](../../../external/iOS-Connector/Code/Uplynk/docs/preplay.md) takes care of the DRM
configuration as part of its Preplay logic: when you request a content-protected asset with the
[`contentProtected`](../../../external/iOS-Connector/Code/Uplynk/docs/preplay.md) flag, the connector sets up the DRM
configuration of the resulting source for you. If you don't use the connector, the Uplynk integration can be found
[here](https://github.com/THEOplayer/samples-drm-integration/blob/master/ios/ContentProtectionIntegration/integration/UplynkDRMIntegration.swift).
