# How to programmatically enable or disable audio tracks on iOS

import Intro from '../../shared/media-tracks/_enable-disable-audio-tracks-intro.mdx';

<Intro />

## Usage

The iOS SDK exposes the audio tracks through [`player.audioTracks`](pathname:///theoplayer/v11/api-reference/ios/Classes/THEOplayer.html#/s:13THEOplayerSDK0A0C11audioTracksAA14AudioTrackList_pvp),
which contains [`MediaTrack`](pathname:///theoplayer/v11/api-reference/ios/Protocols/MediaTrack.html) objects with an `enabled` property.

```swift
// enable a specific audio track
self.player.audioTracks[indexOfRequestedAudioTrack].enabled = true
```
