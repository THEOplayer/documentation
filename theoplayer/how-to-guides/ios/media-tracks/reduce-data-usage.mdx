## 1. Lower the target buffer

<TargetBuffer />

The iOS SDK does not allow you to change the target buffer.
Its [ABR API](pathname:///theoplayer/v11/api-reference/ios/Protocols/ABRConfiguration.html) only allows you to change the ABR strategy,
and to limit the bitrate and resolution of the renditions considered for ABR.

## 2. Manage preloading

<Preloading />

```swift
theoplayer.setPreload(.auto)
```

## 3. Choose the renditions considered for ABR

<Renditions />

See [how to programmatically select a video track quality](./select-video-track-quality.mdx)
to learn how to limit the qualities considered for ABR.
