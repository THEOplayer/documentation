## Passing the license through the player configuration

Include the license in the player configuration, either by passing the license as a string
or by passing a license URL:

```typescript
const config: PlayerConfiguration = {
  license: 'your_license_here',
};
```

```typescript
const config: PlayerConfiguration = {
  licenseUrl: 'your_licenseUrl_here',
};
```

Pass this configuration to the `<THEOplayerView>` component:

```tsx
<THEOplayerView config={config} />
```

If no valid license can be found, the player will throw a license error.
